# Lumina-Reader Constitution

## Core Principles

### I. Modularity First
Changes MUST remain modular, composable, and easy to evolve. Prefer reuse over duplication.

### II. Regression Safety
Every change MUST include explicit validation so existing functionality does not break.

### III. Clear User Control
High-impact actions MUST remain transparent and user-controllable with clear feedback.

### IV. Quality and Maintainability
Code MUST stay clean, testable, and minimize technical debt.

## Governance

Constitution updates require rationale and compatibility consideration.
